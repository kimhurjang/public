# 🌿 만화방초 – 자연 정원 홍보 및 예약 통합관리 시스템
> 경남 고성의 민간 정원 **‘만화방초’** 운영을 디지털화하기 위해 제작된 웹 기반 통합 시스템입니다.  
> 사용자는 웹을 통해 정원 예약이 가능하며, 관리자는 예약 승인, 일정 차단, 시설 관리를 효율적으로 수행할 수 있습니다.


## 📌 목적
- 민간 정원의 오프라인 예약 업무를 온라인으로 전환  
- 사용자와 관리자가 각자 필요한 정보를 효율적으로 처리할 수 있도록 UI/UX 구현  
- 통합 예약, 일정, 회원, 게시판 관리 기능 제공


## 🧩 주요 기능

### 사용자 기능
- 카카오 소셜 로그인
- 예약 달력 기반 날짜 선택
- 인원/식사/꽃 옵션에 따른 금액 자동 계산
- 본인 예약 내역 확인 및 상태에 따른 수정/삭제 제한

### 관리자 기능
- 회원 관리 (가입/탈퇴 회원 구분)
- 예약 현황 리스트 및 상태 변경 (대기 → 확정 → 취소)
- 예약 확정 시 일정 차단 자동 연동
- 시설(홀) 정보 등록/수정
- 게시판 및 게시글 그룹 관리


## 🗂️ 프로젝트 구조
- `src/main/java/com/example/mhbc/`
  - `controller/` : 사용자/관리자 컨트롤러
  - `dto/` : DTO 클래스
  - `entity/` : JPA Entity 클래스
  - `repository/` : JPA Repository
  - `service/` : 비즈니스 로직
- `src/main/resources/`
  - `templates/` : Thymeleaf HTML 템플릿
  - `static/` : CSS, JS, 이미지 등 정적 자원

## 💻 사용 기술 스택
| 구분       | 기술 |
|------------|------|
| Backend    | Spring Boot, JPA |
| Database   | PostgreSQL |
| Frontend   | Thymeleaf, JavaScript, jQuery |
| Authentication | Spring Security, OAuth2 (카카오 로그인) |
| 기타       | AOS, bxSlider, FullCalendar 등 활용 |
